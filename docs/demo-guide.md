# 시연 가이드 (로컬)

## 준비

1. 터미널 1: `cd backend` → `py app.py` (macOS·Linux는 `python3 app.py`)
2. 브라우저에서 `http://127.0.0.1:8000/health` 확인 → `{"status": "ok", ...}`
3. 터미널 2: `cd frontend` → `npm run dev`
4. 브라우저에서 `http://localhost:5173` 접속
5. 조건 입력 화면 왼쪽에 "데이터 기준일"이 보이면 연결 완료

## 시연 순서

| 단계 | 할 일 | 보여줄 것 |
| --- | --- | --- |
| 1 | "예시로 체험하기" → "자격 진단하기" | 입력 한 번으로 판정 |
| 2 | 판정 결과 화면 | 항목별 충족·확인 필요, 기준값, 추가 확인 항목, 공고 원문 링크 |
| 3 | "맞춤 주택 보기" | 참고용 공고 목록, 모집 상태, 참고 임대료, 정렬 |
| 4 | "조건 바꾸기" → 월 평균 소득 `600` → 진단 | 미충족 항목과 초과 금액 |

## 예시 입력값

| 항목 | 기본 충족 | 소득 초과 |
| --- | --- | --- |
| 만 나이 | 26 | 26 |
| 월 평균 소득 | 250만원 | 600만원 |
| 총 자산 | 5000만원 | 5000만원 |
| 혼인 상태 | 혼인 중 아님 | 혼인 중 아님 |
| 무주택 여부 | 무주택 | 무주택 |
| 청약통장 | 가입 | 가입 |
| 희망 지역 | 오산시 전체 | 오산시 전체 |

## 자주 나는 오류

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| "판정 서버에 연결하지 못했어요" | 백엔드가 꺼져 있음 | 터미널 1에서 `py app.py` 실행 후 "다시 시도" |
| 추천 화면에서 500 오류 | Windows에 시간대 데이터(tzdata) 없음 | `py -m pip install tzdata` 후 백엔드 재시작 |
| `python3`가 실행되지 않음 | Windows 스토어 연결 | `py app.py` 사용 |
| `npm run dev`에서 package.json 없음 | 저장소 루트에서 실행함 | `cd frontend` 후 실행 |
| 새로고침하면 첫 화면으로 돌아감 | 입력값을 저장하지 않는 구조 | 새로고침 대신 화면의 "다시 시도"·"조건 수정하기" 버튼 사용 |

## 시연 중 말하지 않을 것

- "신청 가능"이라고 말하지 않기. 결과는 "기본 조건 충족, 추가 확인 필요"
- 추천 목록을 "자격 충족 주택"이라고 말하지 않기. "지역·월세 기준 참고용 공고"
