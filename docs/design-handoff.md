## 3. 화면 규칙

- 앰버로 채운 요소는 화면마다 주요 버튼 하나만
- 판정은 색 + 글자로 함께 표시 (충족 / 확인 필요 / 미충족)
- '신청 가능' 쓰지 않기 → '기본 조건 충족', '참고용'
- 입력 글자 16px 이상, 터치 영역 44px 이상
- 노을 이미지는 `mask-image`로 위아래·양옆을 바탕색으로 흐리게 처리 (경계선 없이)

## 4. 화면별 작업 순서

1. **공통**: `Layout.jsx` 헤더 로고를 `<Logo />`로 교체, 헤더 오른쪽에 단계 표시(조건 입력 → 자격 판정 → 추천 주택)
2. **메인 `MainPage.jsx`**
   - 히어로: 세리프 제목 + 나이 입력 + '자격 진단 시작' + '진행 방식 보기', 아래에 판정 결과 목업 + 노을 이미지
   - 나이 입력값을 `navigate('/condition', { state: { condition: { age } } })`로 넘기기
   - 기능 소개: 탭 4개(자격 판정 / 추천 주택 TOP 3 / 정책 추천 / 참고용 공고). `role="tablist"`, 방향키 이동
   - 진행 방식(3단계 타임라인) → FAQ(2단 아코디언) → CTA(노을 배경) → 푸터(`fit-ink`)
3. **조건 입력 `ConditionPage.jsx`**
   - 3단: 왼쪽 단계 목록 / 가운데 폼(최대 600px) / 오른쪽 '입력한 조건' 요약
   - 메인에서 넘어온 나이를 1단계에 채우고 "메인 화면에서 입력한 나이를 가져왔어요" 표시
   - 우선순위: 드롭다운 3개 → 조건 칩 4개, 누른 순서대로 `priority_1~3`
   - 오른쪽 요약의 기준값은 화면에 고정하지 말고 판정 기준 데이터에서 받기
4. **판정 결과 `ResultPage.jsx`**
   - 상단: 제목 + 충족·확인 필요·미충족 숫자 + 항목 수만큼 막대
   - 왼쪽: 항목별 판정 표, '공고문에서 확인할 내용'
   - 오른쪽: '다음 단계' 카드(흰 바탕 + 앰버 버튼), 정책 추천 카드
5. **추천 주택 `RecommendPage.jsx`**
   - TOP 3 리스트형: 순위 숫자(세리프) / 공고 정보 / 원형 점수 3개 / 추천 점수 / 펼치기
   - TOP 3 제목 줄에 '참고용 공고 N건 보기 ↓' 링크
   - 0건 상태: 빠진 이유(예: 접수 마감 6건) + '참고용 공고 보기' + '조건 수정'
   - 참고용 공고: 표 형식, 월 임대료 낮은 순 기본 정렬
